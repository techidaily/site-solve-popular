**JammText Version 1.1 Is Now Available**

MixCity Inc (creators of [JammText](https://tools.techidaily.com/pcdj/products/)) has just announced a major version 1.1 update to [JammText](https://tools.techidaily.com/pcdj/products/). The new 1.1 release of [JammText](https://tools.techidaily.com/pcdj/products/) includes many significant and highly-requested feature updates that DJs and KJs are really going to love. The new ‘Karaoke Mode’ means [Karaoki](https://tools.techidaily.com/pcdj/products/) users can get in on the interactive fun, too.

**Some of the key highlights of this major update are as follows:**

#### Custom branding

In addition to the custom advertisements you could display on screen in previous versions of [JammText](https://tools.techidaily.com/pcdj/products/), Pro tier account users can also customize the branding entirely. The application will use the brand name and social media username you specify. For example: If you enter “Vynil Squad” as your brand, [JammText](https://tools.techidaily.com/pcdj/products/) will show “Vynil Squad Picture Message” when you receive a blank MMS. In addition, you can replace the texting number with equivalent letters. For example, instead showing 212-679-3866, you can show 212-679-FUNN.

[VIEW LARGER IMAGE ![JammText on top of music videos screen](https://i0.wp.com/pcdj.com/wp-content/uploads/2016/09/jt_screenshot_over_video.png?fit=300%2C169&ssl=1 "JammText on top of music videos screen")](https://i0.wp.com/pcdj.com/wp-content/uploads/2016/09/jt%5Fscreenshot%5Fover%5Fvideo.png?fit=1030%2C579&ssl=1)

#### Improved display performance

The display has been optimized to show smoother transitions and use fewer resources. While testing the [JammText](https://tools.techidaily.com/pcdj/products/) team found a significant reduction in CPU usage compared to the previous version.

#### Manual message approval off

Sometimes you don’t want to be bothered with manually approving messages to be displayed. Version 1.1 of [JammText](https://tools.techidaily.com/pcdj/products/) now includes an option to skip manual approval for events where you don’t need to manually approve. For example, if you just want to use a social media feed at a conference, you can disable texting and disable manual approval. Of course, messages will still be rejected if they include one of the filtered words.

#### New Karaoke Mode

Karaoki software users have found uses for [JammText](https://tools.techidaily.com/pcdj/products/) that the [JammText](https://tools.techidaily.com/pcdj/products/) team had not considered. Using [JammText](https://tools.techidaily.com/pcdj/products/) at a karaoke night. Version 1.1’s new karaoke mode option will automatically place [JammText](https://tools.techidaily.com/pcdj/products/) in banner mode and prevent showing pictures (so that lyrics are not covered). This feature allows those who are not singing a way to still interact and have fun by texting the screen.

#### Support for 4k screens

[JammText](https://tools.techidaily.com/pcdj/products/) now works on 4k resolution screens. Show messages and pictures with stunning clarity.

[VIEW LARGER IMAGE ![Text messages to screen with JammText](https://i1.wp.com/pcdj.com/wp-content/uploads/2016/09/jt_screenshot_chat_king_kong.png?fit=300%2C169&ssl=1 "Text messages to screen with JammText")](https://i1.wp.com/pcdj.com/wp-content/uploads/2016/09/jt%5Fscreenshot%5Fchat%5Fking%5Fkong.png?fit=1030%2C582&ssl=1)

#### Quicker to display new messages and pictures

The latest display prioritizes new messages even more than previous versions so that if you get flooded with new messages, they will be displayed as quickly as possible. No more waiting around to see your latest text.

#### Export pictures during an event

Now you can export the event’s pictures before your event has ended. This provides you with various new possibilities. Run photo contests or pick some to post on social media.

**JammText version 1.1 is a free update for all customers.**
