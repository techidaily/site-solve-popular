## Sing Along with Ease: Discover the Upgraded Features of the Karaoki Beta Software for DJs

[![](https://i2.wp.com/pcdj.com/wp-content/uploads/2015/09/karaokibetasept-coverimage.jpg?resize=530%2C298&ssl=1)](https://i2.wp.com/pcdj.com/wp-content/uploads/2015/09/karaokibetasept-coverimage.jpg?fit=530%2C298&ssl=1 "karaokibetasept-coverimage")

_A new Karaoki Beta version is available for download._

This latest iteration of Karaoki, our **[karaoke software](https://tools.techidaily.com/pcdj/products/)** hosting solution designed for professional karaoke host and venues, includes a handful of new additions such as a larger search box area (_which can be accessed by simply typing on your keyboard, no need to click into the box first_), an option to print out a track list while in [solo artist mode](https://tools.techidaily.com/pcdj/products/), updated audio and video engine, a few new prompts to improve usability, a smattering of graphics changes and various bug fixes and overall performance improvements.

[VIEW LARGER IMAGE (NEW SEARCH BOX) ![New Karaoki Skin](https://i0.wp.com/pcdj.com/wp-content/uploads/2015/09/karaokibeta-screenshot-sep.jpg?fit=300%2C172&ssl=1 "New Karaoki Karaoke Software Version")](https://i0.wp.com/pcdj.com/wp-content/uploads/2015/09/karaokibeta-screenshot-sep.jpg?fit=1030%2C591&ssl=1)

All Karaoki users are welcomed to download and try the new release, which you can access in Karaoki under: **Options -> Utilities -> Check for Update**. You will see the new Beta 0.8.5735 available for download and installation. If you’re not happy with the Beta’s performance you can roll back to the public release under ‘**Check For Update**‘.

### **All Changes And Updates Included In Karaoki Build #0.8.5735**

**_Bug Fixes/ Potential Fixes:_** 
• Potential hang when upgrading from older builds.  
• Singer data screen TAB order.  
• When adding track to rotation from history, the the QTY always displayed ‘0’.  
• Updated Audio/Video engine.  
• Intermittently unable to delete singer from Rotation.  
**_Added:_** 
• User prompted to save singer data when starting a new or loading existing show.  
• Option to print out track list when in solo mode.  
• Functionality added to remote connections/plugin interface for future plugin development.  
• Prompt box to save singers data when removing them from the show or starting a new show.

Changes:  
• Start-up Flash screen sequence.  
• Search Box re-sized (larger typing area).  
• Graphical Changes to screens.
